# Marca do LENDA

| Arquivo | Para quê |
|---|---|
| `lenda-perfil.png` | Foto de perfil (TikTok, YouTube, Instagram): escudo + LENDA, 2048×2048, tudo dentro do círculo. |
| `lenda-perfil-escudo.png` | Foto de perfil só com o escudo: lê melhor bem pequeno. 2048×2048. |
| `lenda-escudo.png` | Escudo com fundo transparente, 2048×2048. |
| `lenda-escudo.svg` | Escudo em vetor (qualquer tamanho, gráfica, camiseta). |
| `lenda-logo-horizontal.png` | Escudo + LENDA lado a lado, fundo transparente, letras brancas (para fundo escuro), 3200×960. |

Gerados por `node scripts/marca/logo.mjs` a partir do escudo do jogo (`public/favicon.svg`) e da fonte Inter
Tight 900 com espaçamento .16em, a mesma do topo do jogo.
