# multfiscal-releases

Manifesto de versões do MultFiscal (`versao_teste.json`) e os pacotes de
instalação publicados em *Releases*.

## OmniChannel 2

Este repositório também abriga o [OmniChannel 2](omnichannel/), a central de
atendimento unificada do suporte: WhatsApp, Telegram, e-mail e o chat do site
numa única caixa de entrada, com o histórico do cliente sempre junto da
conversa. Instruções de instalação, configuração dos canais e da API estão em
[`omnichannel/README.md`](omnichannel/README.md).
